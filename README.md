# 바코드 조회 웹 · 시제품

휴대폰으로 상품 바코드를 비추거나 포장 사진을 찍으면, 미리 넣어 둔 상품 데이터에서 상품을 찾아 **용량별 가격**을 보여주는 웹입니다. 앱 설치 없이 아이폰 Safari와 안드로이드 크롬에서 동작합니다.

## 찾는 방법

| 방법 | 설명 |
|---|---|
| 카메라로 스캔 | 바코드 실시간 인식 (안드로이드 크롬은 내장 인식기, 아이폰은 ZXing) |
| 사진으로 찍기 | 바코드를 한 장 찍어서 인식 |
| 포장 사진으로 찾기 | 포장에 인쇄된 **영어 이름**을 폰에서 읽어(Tesseract), 데이터의 `영문명`과 가장 비슷한 상품을 찾음. 비슷한 후보도 함께 보여줌 |
| 번호 직접 입력 | 바코드가 훼손됐을 때 |

같은 상품의 다른 용량은 한 묶음으로 보여주고, **용량 버튼을 누르면 그 용량의 가격**이 나옵니다.
- `영문명`이 같은 상품끼리 한 묶음
- `영문명`이 비어 있으면 상품명에서 용량(2kg, 85g, 374g / 6 …)을 뗀 이름이 같은 것끼리 한 묶음

## 상품 데이터 (구글시트 또는 엑셀)

열 이름: `바코드`, `상품명`, `영문명`, `가격`, `이미지`(선택), `메모`(선택). 다른 열을 추가하면 그 이름 그대로 화면에 표시됩니다. `products.csv`가 지금 들어 있는 데이터(토스플레이스 양식에서 옮긴 101개)이고 양식으로 그대로 쓸 수 있습니다.

### 구글시트로 관리 (추천)
1. 구글시트에서 파일 > 가져오기 > `products.csv` 업로드 (**"텍스트를 숫자, 날짜로 변환" 해제** — 바코드 앞의 0을 지키려고)
2. 공유 > 일반 액세스를 **"링크가 있는 모든 사용자 (뷰어)"**로 변경
3. 주소창의 시트 주소를 `settings.js`의 `sheetCsvUrl`에 붙여 넣기 (또는 웹 화면 "데이터 관리"에 입력하면 그 폰에만 적용)

이후로는 시트만 고치면 웹을 다시 열 때 바로 반영됩니다. 시트를 못 읽으면 마지막으로 읽은 내용을 보여줍니다.

### 엑셀로 관리
엑셀에서 "CSV UTF-8" 또는 "CSV"로 저장해 `products.csv`를 바꿔 올리면 됩니다. (한글 CSV 둘 다 읽음)

### 주의
- 바코드가 `7.41986E+10`처럼 바뀐 줄은 읽을 수 없어 건너뜁니다. 바코드 열은 **텍스트 서식**으로 두세요
- 앞의 0이 지워진 바코드(`74198612239`)는 같은 상품으로 찾으니 괜찮습니다
- 영문명 칸에 `|`로 여러 이름을 넣으면 모두 비교합니다 (예: `Pacific Stream Canine | Smoked Salmon`)
- 이미지 칸: https 이미지 주소 또는 구글 드라이브 공유 링크

## 관리자 모드 (웹에서 바로 상품 고치기)

관리자 비밀번호로 들어가면 상품 카드에 **수정 / 다른 용량 추가 / 삭제** 버튼이 생기고, 등록 안 된 바코드는 **시트에 바로 등록**할 수 있습니다. 저장하면 구글시트에 바로 들어가서 모든 폰에 보입니다. 상품 사진은 구글 드라이브의 "바코드조회 상품사진" 폴더에 저장됩니다. 이 방식이면 시트를 공개할 필요가 없습니다.

한 번만 설정하면 됩니다 (5분):
1. 상품 구글시트를 열고 **확장 프로그램 > Apps Script**
2. 기본 코드를 지우고 `apps-script/Code.gs` 내용을 붙여 넣고 저장
3. 왼쪽 **프로젝트 설정(톱니바퀴) > 스크립트 속성 > 속성 추가**: 이름 `ADMIN_PIN`, 값은 관리자 비밀번호 (6자리 이상 추천)
4. 오른쪽 위 **배포 > 새 배포 > 유형: 웹 앱**, 실행 사용자: **나**, 액세스 권한: **모든 사용자** → 배포 (처음에 구글 권한 허용 창이 뜨면 허용)
5. 나온 웹 앱 주소(`https://script.google.com/macros/s/…/exec`)를 `settings.js`의 `adminApiUrl`에 붙여 넣기

비밀번호는 10번 틀리면 10분 동안 막힙니다. 비밀번호를 바꾸려면 3번의 값만 고치면 됩니다. Code.gs를 고친 뒤에는 **배포 > 배포 관리 > 수정 > 새 버전**으로 다시 배포해야 반영됩니다.

## 실행과 배포

**휴대폰 카메라는 https 주소에서만 켜집니다.** 빌드 도구가 없는 정적 사이트라 폴더째 올리면 됩니다 (Netlify Drop, GitHub Pages, Cloudflare Pages 등).

```bash
npm start          # http://localhost:8080 (PC 확인용)
npm run preview    # dist/ 에 파일 하나짜리 미리보기 생성
```

## 파일
- `index.html`, `style.css`, `app.js`, `settings.js`: 화면, 동작, 시트 주소
- `products.csv`: 상품 데이터
- `vendor/zxing-0.21.3.min.js`: 바코드 인식 (Apache-2.0)
- `vendor/tesseract/`: 영어 글자 인식 Tesseract.js 5.1.1 + 영어 데이터 (Apache-2.0)
- `test-barcodes.html`: products.csv 상품의 바코드를 화면에 띄우는 시험용 페이지
